## 💻 ⟨ بنية التشغيل والتثبيت ⟩

<img src="https://img.shields.io/badge/Platform-Termux%20%7C%20Linux%20%7C%20VPS-00ffff?style=for-the-badge&labelColor=000000"/>
<img src="https://img.shields.io/badge/Runtime-Node.js-00ffff?style=for-the-badge&logo=node.js&labelColor=000000"/>

</div>

### 📱 التثبيت على Termux (Android)

```bash
# ◈ الخطوة الأولى — إعداد البيئة
termux-setup-storage
pkg update -y && pkg upgrade -y

# ◈ الخطوة الثانية — تثبيت المتطلبات
pkg install git nodejs -y

# ◈ الخطوة الثالثة — استنساخ المستودع
git clone https://github.com/moreand458-eng/ESCANOR-ONLY.git
cd ESCANOR-ONLY

# ◈ الخطوة الرابعة — تثبيت الحزم
npm install

# ◈ الخطوة الخامسة — تشغيل البوت
npm start
```

### 🖥️ التثبيت على VPS / Linux

```bash
# ◈ تثبيت Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs git

# ◈ استنساخ وتشغيل البوت
git clone https://github.com/moreand458-eng/ESCANOR-ONLY.git
cd ESCANOR-ONLY && npm install && npm start
```
